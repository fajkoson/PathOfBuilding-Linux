# SimpleGraphic Linux runtime

This directory contains the native runtime imported from PathOfBuildingCommunity.
The source revision is recorded in `../simplegraphic-upstream.txt`.
Build from the repository root using `./build.sh`; see `../../../docs/linux-build.md`.
Shared platform code retains upstream Windows conditionals where useful for
future runtime merges, but this fork builds Linux targets only.
Original licensing is retained in `LICENSE`.
